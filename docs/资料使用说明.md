# 馆藏资料和公开样例

本题资料描述东馆、西馆和南馆组成的虚构馆网，供“图书馆跨馆还书助手”检索和解释归还结论。所有相对路径以 `/home/project/exam` 为起点。

## 馆点和馆藏类别

`data/branches.json` 保存馆点代码与名称。E 对应东馆，W 对应西馆，S 对应南馆。借出馆是原先办理借出手续的分馆，拟还馆是读者这次计划交回馆藏的分馆。接口用 `borrow_branch` 和 `return_branch` 分别提交这两项。

馆藏类别包括普通纸质图书和随书附件。普通纸质图书包括一般纸版读物、常见小说等。随书附件指书中附送的光盘、配套光碟等附带物，附带物单独归还时按随书附件处理。仅说“这个”或“借的东西”尚未明确类别。

## 规则资料

`data/rules.jsonl` 每个非空行是一条资料，字段为 `id`、`title`、`text`，共 12 条，编号 R01 至 R12。`id` 是在答复中展示的资料编号，`title` 为标题，`text` 为正文。检索编码文本按 `title + "：" + text` 拼接，中间使用一个全角冒号，冒号两侧不额外添加空格，资料顺序采用文件非空行顺序。

R01 是普通纸质图书的通还总则，R02 用于随书附件，R03 是普通纸质图书拟还南馆时适用的接收细则。判断时先核对馆藏类别和馆点是否满足条款条件，R03 在其适用范围内优先于通还总则。每个明确的归还结论引用一条决定性规则。

其余资料解释馆点、术语、办理信息和查询范围，结合实际适用条件使用。馆藏库存、当前借阅记录、开放时间、电子书续借等事项均有各自的服务渠道，本组归还资料没有提供其查询结果或办理方法。

## 模型和索引

指定的本地语义编码模型在 `models/course_semantic_model/`，资源摘要见 `docs/model_manifest.json`。该模型将文本编码为向量，应用结合向量检索结果、馆点条件及资料正文组织答复。基础模型按题目给定版本使用。

生成的索引位于 `submission/artifacts/index.npz`，元数据位于 `submission/artifacts/index.meta.json`。索引覆盖全部规则资料，各行向量与资料非空行顺序一一对应。编码、归一化及摘要格式见 `docs/接口与工具说明.md`。

## 公开采集输入

`data/public_cases.json` 保存每道题实际采集时使用的固定输入。

| 字段 | 用途 |
| --- | --- |
| `embed_texts` | 0102 的两条编码输入 |
| `preview_format` | 0201 的答复格式预览 |
| `preview_limits` | 0202 的候选与长度限制预览 |
| `answers` | P01 至 P08 的咨询请求 |
| `answer_run` | 0302 的请求顺序 |
| `reuse_run` | 0401 的请求顺序 |
| `web_case` | 0501 的网页操作输入 |
| `benchmark` | 0402 的公开性能测量输入 |

这些输入便于观察和采集服务输出，规则检索使用 `data/rules.jsonl`。公开用例保存的是接口输入，应用应根据实际问题、馆点和检索依据得出结果。
